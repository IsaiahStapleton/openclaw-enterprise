### Credentialed execution and reporting

The reusable live workflow checks trusted workflow identity and admits targets in main ancestry, version tags **or repository branch history**; this is broader than the reviewed-main-only policy proposed for Enterprise. `no-push-artifact` requires an exact lowercase commit SHA. Missing selected model credentials fail preflight. Docker E2E still runs non-live diagnostics when credential setup fails, requires `summary.json`, and uploads diagnostics even after failures. Advisory profiles can turn failures into warnings/success, while mode selection can skip steps; a green live job therefore needs case-level interpretation. [Target validation](https://github.com/openclaw/openclaw/blob/97abb65691d97ee95c977a9a4ede2ef221d6929c/.github/workflows/openclaw-live-and-e2e-checks-reusable.yml#L574-L682), [image revision](https://github.com/openclaw/openclaw/blob/97abb65691d97ee95c977a9a4ede2ef221d6929c/.github/workflows/openclaw-live-and-e2e-checks-reusable.yml#L785-L804), [summary/artifacts](https://github.com/openclaw/openclaw/blob/97abb65691d97ee95c977a9a4ede2ef221d6929c/.github/workflows/openclaw-live-and-e2e-checks-reusable.yml#L1549-L1594), [credential preflight](https://github.com/openclaw/openclaw/blob/97abb65691d97ee95c977a9a4ede2ef221d6929c/.github/workflows/openclaw-live-and-e2e-checks-reusable.yml#L3720-L3760), [advisory result](https://github.com/openclaw/openclaw/blob/97abb65691d97ee95c977a9a4ede2ef221d6929c/.github/workflows/openclaw-live-and-e2e-checks-reusable.yml#L4324-L4342).
